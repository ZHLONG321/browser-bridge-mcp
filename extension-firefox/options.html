Firefox Browser Bridge

Connect to the same dedicated Browser Bridge service as your other browsers.

Enabled control permits privileged browser API calls and function arguments from the local service. Turning it off stops new calls and removes bridge event subscriptions; previous browser changes remain.

Optional browser permissions

All permissions are selected by default. Enabling native control and clicking Save requests the selected permissions, including access to all websites. Confirm Firefox's permission prompt to finish enabling control.

Connection



To include private windows, allow this extension in private browsing in Firefox's add-on details. Normal and private tabs remain separately identified.


Native RDP debugging is a separate connection. Start the intended Firefox's TCP debugger listener, then use the client's discover with its explicit port. A connection may show Firefox's confirmation dialog; authorize that interaction first. This extension does not change debugging preferences or start a browser.
